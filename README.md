# سوقلي — Sawqli

واجهة متجر إلكتروني عربية (RTL) للأجهزة الإلكترونية والكهربائية — **واجهة فقط (Frontend Only)** بدون أي API أو خادم.
يبدأ المتجر بحالة نظيفة بدون منتجات أو طلبات أو عملاء — تُضاف البيانات من لوحة الإدارة ويُنشئ العملاء حساباتهم من صفحة التسجيل. تُحفظ البيانات في `localStorage`، لذا يعمل التطبيق بالكامل بدون إنترنت.

مبنية حسب الوثيقة التنفيذية `design md` (تطبيق العميل + لوحة الإدارة).

## التقنيات

| العنصر | التقنية |
| --- | --- |
| اللغة | TypeScript |
| الواجهة | React 19 + Vite 8 |
| التنسيق | Tailwind CSS v4 (CSS-first، بدون ملفات إعداد) |
| التنقل | React Router 7 |
| الأيقونات | lucide-react |
| الخط | Cairo Variable (مضمّن محليًا عبر `@fontsource-variable/cairo`) |
| الصور | كل الصور SVG مولّدة داخليًا (`src/lib/artwork.ts`) — لا تحتاج شبكة |

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # بناء للإنتاج إلى dist/
npm run preview    # معاينة بناء الإنتاج على 4173
npm run typecheck  # فحص أنواع TypeScript
npm run smoke      # اختبار تصيير لكل المسارات (React + jsdom)
npm run flows      # اختبار تدفقات حرجة: دخول الإدارة، إضافة للسلة، الدفع
npm test           # typecheck + smoke + flows
```

## النشر على Vercel

- Framework Preset: **Vite** (أو Other) — أمر البناء `npm run build`، ومجلد الإخراج `dist`.
- ملف `vercel.json` يحتوي على إعادة توجيه SPA لكل المسارات إلى `index.html` + ترويسات تخزين مؤقت للأصول.

## بنية المشروع

```
src/
  App.tsx                 # كل المسارات + الثيم + ScrollToTop + حماية المسارات
  main.tsx                # نقطة الدخول + الخط + إزالة شاشة التحميل الأولية
  index.css               # توكنات التصميم (@theme) والأنيميشن والأدوات
  types.ts                # نموذج البيانات الكامل
  data/seed.ts            # البيانات الأولية (أقسام وعلامات تجارية وصفحات وإعدادات — بدون منتجات أو طلبات)
  lib/                    # utils، artwork (SVG)، i18n، pricing، query، orders
  store/                  # AppProviders: Toast → AppData → Language → Auth → Cart → Wishlist (localStorage)
  hooks/                  # useRequireAuth، useBack
  components/
    ui/                   # Button, form, overlay (Modal/BottomSheet/ConfirmDialog/Dropdown), display، Toast
    layout/               # AppShell, TopBar, BottomNav, Screen, BootScreen, ExpiredSessionModal
    customer/             # بطاقات المنتج، السلايدر، الفلاتر، المراجعات، المعرض، مودالات العناوين...
    admin/AdminUI.tsx     # عدة لوحة الإدارة: AdminPage, Card, StatCard, DataTable, LineChart, BarChart, DonutChart
  pages/                  # customer/ و admin/
scripts/smoke.mjs         # يجب أن تُصيَّر كل الشاشات بدون أخطاء وقت تشغيل
scripts/flows.mjs         # اختبار التدفقات الحرجة (تسجيل دخول، سلة، دفع)
```

### تفاصيل مهمة
- **حالات الجلسة:** تنتهي جلسة العميل بعد 30 دقيقة من تسجيل الدخول، ويمكن محاكاة الحالة مباشرة من
  `الإعدادات → إعدادات تقنية → اختبار حالات الواجهة`.
- **الشعار والأيقونة:** يُرفعان من `الإعدادات → الإعدادات العامة` ويُطبَّقان فورًا (الشريط العلوي، لوحة الإدارة، تبويب المتصفح).
- **الشحن/الدفع/الضريبة:** كلها محسوبة فعليًا في `src/lib/pricing.ts` وتُستخدم في السلة والدفع والطلبات.
- **تصدير البيانات:** من جداول المنتجات والطلبات والعملاء (CSV يفتح في Excel)، واستيراد المنتجات من CSV.

## الأداء

- **Code Splitting:** كل شاشات لوحة الإدارة + الشاشات الثانوية في تطبيق العميل تُحمَّل عند الطلب،
  فالحزمة الأولى للمتجر ≈ 95KB مضغوطة (بدل 200KB)، ولوحة الإدارة كاملة لا تُحمَّل إلا عند فتح `/admin`.
- الصور كلها SVG داخلية (لا طلبات شبكة)، والخط Cairo مُضمَّن محليًا.
- كل البيانات محلية في `localStorage` — لا انتظار لأي API.

## ملاحظات مهمة

- **لا يوجد خادم:** المصادقة، الطلبات، الكوبونات، الإشعارات... تُدار محليًا. زر «إعادة تعيين بيانات المتجر»
  في `الإعدادات → إعدادات تقنية` يعيد كل شيء لحالة البداية النظيفة.
- **حالات عامة مطبّقة:** شاشة تحميل مع انتقال لشاشة خطأ بعد 10 ثوانٍ، شريط انقطاع الاتصال (أحمر/أخضر)،
  تنبيه انتهاء الجلسة (يظهر بعد 30 دقيقة من تسجيل الدخول، ويمكن إنهاء الجلسة من `الإعدادات → إعدادات تقنية`)،
  صفحة 404، وإشعارات Toast بأربعة أنواع (تختفي بعد 3 ثوانٍ، أو 5 مع زر إجراء).
- **تخصيص الهوية:** الألوان والنصوص قابلة للتعديل من لوحة الإدارة وتُطبَّق فورًا على التطبيق.
- **الهوية اللونية:** اللون الأساسي بنفسجي «#7c3aed» كما في الوثيقة (وثانوي أزرق «#2563eb»)،
  مع 5 أنظمة ألوان جاهزة في `الإعدادات → هوية المتجر`.
